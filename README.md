1. Descripción breve de lo que hace el programa

El programa permite registrar la información de cinco libros ingresados por el usuario. Para cada libro se almacenan el título, el autor, el año de publicación, la edición y la cantidad de páginas. Una vez capturados todos los datos, el programa muestra la información de cada libro en pantalla.



2. Datos de entrada

El usuario debe ingresar los siguientes datos para cada uno de los cinco libros:

Título
Autor
Año de publicación
Edición
Cantidad de páginas



3. Datos que procesa

El programa almacena los datos ingresados por el usuario en objetos de la clase Libro. Posteriormente, recorre el arreglo de libros y procesa la información para mostrarla de forma organizada en la consola.



4. Datos de salida

El programa muestra en pantalla la información registrada de los cinco libros, incluyendo:

Título
Autor
Año de publicación
Edición
Cantidad de páginas



5. Importancia de utilizar encapsulación en la POO

La encapsulación es importante porque protege la información de los objetos, evitando que los atributos sean modificados directamente desde otras partes del programa. En este ejercicio, los atributos de la clase Libro son privados y solo pueden utilizarse mediante métodos públicos, lo que ayuda a mantener un mejor control sobre los datos y hace que el programa sea más seguro y organizado.



6. Cómo compilar y ejecutar el programa
Abrir Visual Studio.

Crear o abrir el proyecto de C++.

Abrir el archivo .cpp y pegar el código del programa.

Guardar los cambios.

Compilar el programa presionando Ctrl + Shift + B o seleccionando Compilar → Compilar solución.

Ejecutar el programa con Ctrl + F5 o haciendo clic en Depurar → Iniciar sin depurar.

Ingresar los datos solicitados y verificar que se muestren correctamente.
